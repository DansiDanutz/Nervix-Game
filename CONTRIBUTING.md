# Contributing from any harness
Open this repository in T3, Claude Code, Codex or another Git-capable harness. Read AGENTS.md, game.md, Roadmap.md and ARCHITECTURE.md first. Use your own branch based on the latest main. Do not reset another contributor’s checkout or overwrite their Blender file. Coordinate binary scene ownership before editing.

Use assets/references/README.md as the shared image gallery; every referenced PNG is in Git. Add original images there, use stable names, update the gallery and SHA256SUMS. For visual changes attach the reference, a Blender render and a screenshot from the actual game camera. Record commands, results and gaps in PROGRESS.md. Submit a pull request; never commit credentials or use real payments or wagers in tests.
