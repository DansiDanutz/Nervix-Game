# Nervix World roadmap
These are acceptance gates, not claims of completion.

1. **Street arrival.** Build from A01–A15. Capture the first settled frame of a fresh session before any input. Compare with A01 at pedestrian eye level: foreground paving, fountain sightline, merchant facades and skyline.
2. **Exploration.** Verify mouse look and interaction, keyboard forward/strafe, collision, door entry and return to the correct street. Test through the ordinary player UI.
3. **OpenPoker.** Match A16 at the entrance and A17 inside, with the A18 roulette table. Compare reference, Blender render and browser frame from the same doorway.
4. **Merchant houses.** Test two independent fixture merchants. Each visitor sees the right owner, assets and app. Verify server rejection for visitor edits and cross-owner edits, and success for an eligible owner.
5. **Release readiness.** Validate Blender exports, run server and app checks, record desktop and mobile performance, and review screenshots before visual sign-off. Track completed work and remaining gaps in PROGRESS.md.
